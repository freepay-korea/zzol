## 2. 간단한 설명 (최대 80자)

```
광고 없이 3초 만에! 손가락 뽑기·제비뽑기로 간식 내기, 순서 정하기, 팀 나누기
```

## 3. 자세한 설명 (최대 4000자)

```
누가 쏠지, 누가 먼저 할지 고민될 때 — 폰 하나만 꺼내세요.
"쫄?"은 광고 없이 바로 시작하는 친구 모임 내기 게임입니다.

■ 손가락 뽑기
- 2~10명이 화면에 손가락을 동시에 올리면 끝!
- 손가락마다 다른 색 네온 원이 생기고, 3초 카운트다운 후 결과 발표
- 1명 당첨 / 여러 명 당첨 / 팀 나누기(2~4팀) 모드
- 당첨자에게 왕관 배지와 화려한 폭죽 효과, 진동까지

■ 제비뽑기
- 2~20명, 꽝 개수 자유롭게 설정
- "커피 쏘기", "설거지 당첨" 같은 벌칙 문구를 직접 입력
- 카드를 한 장씩 뒤집는 긴장감 있는 연출
- 설정은 자동 저장되어 다음에도 바로 시작

■ 이런 분께 추천해요
- 회식·모임에서 계산할 사람 정하기
- 간식 내기, 커피 내기
- 게임 순서, 발표 순서 정하기
- 체육 시간·MT 팀 나누기

■ 이래서 편해요
- 광고 없음, 회원가입·로그인 없음
- 개인정보를 수집하지 않음
- 공정한 무작위 추첨 (암호학적 난수 사용)
```

## 5. 앱 콘텐츠 설문 (Play Console > 정책 > 앱 콘텐츠)

- **개인정보처리방침**: 위 URL 입력
- **광고**: 앱에 광고가 없음
- **앱 액세스 권한**: 모든 기능을 별도 제한 없이 사용할 수 있음 (로그인 없음)
- **콘텐츠 등급(IARC)**: 카테고리 "게임" 선택 → 폭력·성적 콘텐츠·도박·사용자 간 소통·위치 공유 모두 "아니요"
  - 참고: 실제 돈이나 재화를 거는 기능이 없으므로 "도박/시뮬레이션 도박"에도 "아니요"
  - 예상 등급: 전체이용가
- **타겟층**: 13세 이상 (예: 13–15, 16–17, 18세 이상). 아동 대상(13세 미만)을 포함하면 가족 정책 심사가 추가되므로 제외 권장
- **데이터 보안(Data safety)**:
  - 앱이 사용자 데이터를 수집하거나 공유하나요? → **아니요**
  - (설정·벌칙 문구는 기기 내 저장만 하고 전송하지 않음. 글꼴 로딩 시 Google Fonts에 일반 웹 요청만 발생)
- **정부 앱 / 금융 기능 / 건강**: 해당 없음
